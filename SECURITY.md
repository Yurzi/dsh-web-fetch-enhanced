# Security Policy

Address allowlists expand network reachability and are treated as a
security-sensitive interface. Read [docs/security.zh-CN.md](docs/security.zh-CN.md)
before deployment or review.

Please report vulnerabilities privately to the repository maintainer. Include
the DeepSeek Harness version, plugin version, minimal Host composition, DNS
answers, expected/actual WebError code, and whether fake-IP, DNS64, or a
transparent proxy is active. Do not include credentials or sensitive response
bodies in a public issue.
